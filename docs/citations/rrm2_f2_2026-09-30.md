- **Identifier:** arXiv:2004.00713, current version **v2** (24 Aug 2020; v1 1 Apr 2020); no comment or journal reference on

## B. P5: transport of stored statistics by the measured movement of reference points

### 7. HopDC, Hopfield-based distribution compensator (Rao et al., arXiv 2026): the nearest match found

- **Identifier:** arXiv:2602.00144, current version **v1** (29 Jan 2026; the only version listed); no comment or journal
  reference, and the PDF reads "Preprint. February 3, 2026". Fetched 2026-09-30. Xuan Rao, Mingming Ha, Bo Zhao, Derong Liu,
  Cesare Alippi.
- **Integrity:** PDF (v1) `pdf_2602.00144v1.pdf` sha256 bb247b25639cd18f87e6403b9e9e4019106c0f804502db25a640f884e5240574;
  abstract page sha256 779ef2c3bc811df0e2bbb7e7ab7ad73205d765344aced5c4d0e850ef1019af74.
- **Mechanism** (agent's reading of §3 and Algorithms 1–2):
  - a fixed set A of unlabeled anchor images is kept for the whole stream;
  - their features under the previous backbone, F_old, are stored;
  - after each task, the drift D = F_new − F_old is measured;
  - for each old class, M pseudo-features are sampled from its stored Gaussian N(µ_c, Σ_c);
  - each pseudo-feature moves by a top-k softmax-attention average of the anchor drifts, weighted by similarity to the anchors
    in the old space;
  - µ_c and Σ_c are re-estimated from the moved samples, and F_old is updated.

  In the experiments, the anchors are 1,024 ImageNet-1K images plus current-task samples, on a pre-trained ViT-B/16.

> we posit that old class prototypes shift consistently with semantically related unlabelled anchors, allowing for precise recalibration without historical exemplars.

> Let A = {ai}N i=1 be a fixed set of unlabeled anchor images.

> this operation effectively computes a weighted average of anchor drifts, where weights are determined by the semantic similarity between the old class samples and the anchors in the original feature space.

> employ an auxiliary set of 1,024 unlabeled anchors drawn from ImageNet-1K (Deng et al., 2009). Following the settings of SLDC (Rao et al., 2026), we also utilize samples of the current task as supplement anchors.

- **Reading.** P5 **close**, and the nearest published form of RRM's transport found in either sweep.
  - **What it shares with RRM:**
    - stored class Gaussians, sampled and transported;
    - a fixed anchor set kept across the stream, with its features stored;
    - the measured movement of the anchors;
    - weights that are a relation to the anchors in the old space.
  - **What differs:**
    - the anchors are external unlabeled images, supplemented by current-task samples, not kept training rows of the stream,
      and they are not replayed;
    - the relation is a kernel (softmax attention) smoother, not RRM's linear ridge relation, so there is no exact recovery
      of a linear drift and no in-span/out-of-span split;
    - the learner is a pre-trained ViT.

  A reader who takes P5 at the level of its wording (stored statistics transported by the measured movement of a kept anchor
  set) may read this as **states**; see the judgement calls. (Claim w2:6.)

### 8. SLDC with auxiliary data enrichment (Rao et al., AAAI 2026)

- **Identifier:** arXiv:2511.09926, current version **v1** (13 Nov 2025; the only version listed), comment "The 40th Annual
  AAAI Conference on Artificial Intelligence (AAAI 2026)", fetched 2026-09-30. Xuan Rao, Simian Xu, Zheng Li, Bo Zhao, Derong
  Liu, Mingming Ha, Cesare Alippi.
- **Integrity:** PDF (v1) `pdf_2511.09926v1.pdf` sha256 4cb1896fa5072ce5a079f3f0d80a98a102c0a38e46e173c1887117e2f121cd46;
  abstract page sha256 a3983ac9f4fd28720430fea64613f44afde5d60c2d204b31985b4a4b6664d520.
- **Mechanism:**
  - α1-SLDC fits A_t = F̃_t F̃_{t−1}ᵀ(F̃_{t−1}F̃_{t−1}ᵀ + γI)⁻¹ on L2-normalised old/new feature pairs;
  - the fit is shrunk toward the identity when the task has few samples;
  - every stored class Gaussian is moved as µ ← A_t µ and Σ ← A_t Σ A_tᵀ (its Algorithm).
  - ADE adds unlabeled auxiliary images from another dataset to the pairs.

> The linear operator At ∈Rd×d for approximating Pt−1→t is obtained by solving the regularized least-square solution

> this paper proposes auxiliary data enrichment (ADE) to improve the prediction by leveraging unlabeled auxiliary data from arbitrary sources.

> ADE operates without requiring labeled data and remains consistent with the exemplar-free continual learning (CIL) framework since it does not preserve any task-relevant data from previous tasks.

- **Reading.** P5 **close**. This is RRM's linear transport of stored Gaussians, a ridge fit in primal form. The pairs are
  current-task features plus external unlabeled data, not kept past rows. (Claim w2:7.)

### 13a. Transport keys (Chaudhury, technical report 2026): a lead from the F3 sweep

- **Identifier:** arXiv:2606.02860, current version **v1** (1 Jun 2026; the only version listed), comment "Technical report
  showcasing results from transport keys", fetched 2026-09-30. Archie Chaudhury (Axionic Labs).
- **Integrity:** PDF (v1) `pdf_2606.02860v1.pdf` sha256 c0fb60558d14a61f3dd90851029c2b86586f46bdd96cda4cfae4757a00f9fbf3;
  abstract page sha256 195ecabd7934699ff517d23ac13a5951fdb3dc3577369e63307d2e2403061983.
- **Mechanism:**
  - after training Task A then Task B, a few Task A examples (anchors) are passed through both checkpoints;
  - an alignment "key" is fitted on the paired activations at an internal interface;
  - the key maps the post-update early network's activations back into the pre-update late network, which is kept together
    with the Task A head.
  - Two key families: per-channel scale and offset, and cross-channel mixing. The report gives no fitting equations.

> We describe transport keys at a systems level as compact interface-alignment operators estimated from a small set of paired anchor activations and evaluated through model stitching.

> Anchors are ordinary examples from the earlier task and are passed through both checkpoints.

> it is inserted between an early portion of a post-update network and a late portion of the pre-update network, and it maps the new activation coordinate system back into a form that the old downstream computation can decode.

- **Reading.** P5 **close**.
  - **The anchor side matches RRM exactly:** a few kept examples of the earlier task, paired features from the old and the
    updated network, and a map fitted on them.
  - **The transported object differs:**
    - it maps live activations new → old into a kept pre-update decoder, rather than carrying stored old-class statistics
      old → new;
    - it needs the old checkpoint, not features stored at the cut.

## Is RRM's transport published? (P5)

**Not found in the full form; the nearest source is closer than anything in the first sweep.**

- **HopDC** (arXiv:2602.00144 v1, 29 Jan 2026) transports stored class Gaussians by the measured drift of a fixed anchor set
  kept for the whole stream. It samples pseudo-features from each stored Gaussian, moves each by a similarity-weighted average
  of the anchor drifts, and re-estimates the statistics.
- **α1-SLDC + ADE** (arXiv:2511.09926 v1, AAAI 2026), by the same group, is a ridge-regularised linear operator applied to
  stored Gaussians as µ ← Aµ, Σ ← AΣAᵀ. It is fitted on current-task features plus external unlabeled data.

RRM's transport is the linear ridge relation of the second applied to a kept anchor set as in the first. It differs from both
in two ways:
- **the anchors:** RRM's are a few raw rows of the stream's own first task, labelled, kept and also replayed through the
  network. HopDC's are 1,024 external unlabeled images plus current-task samples;
- **the relation:** RRM's is fixed at each class's cut, and the out-of-span part is carried stale (DECLARATION.md §1).

The closest quotes:

> we posit that old class prototypes shift consistently with semantically related unlabelled anchors, allowing for precise recalibration without historical exemplars.

> Let A = {ai}N i=1 be a fixed set of unlabeled anchor images.

> this operation effectively computes a weighted average of anchor drifts, where weights are determined by the semantic similarity between the old class samples and the anchors in the original feature space.

(HopDC, arXiv:2602.00144 v1.)

> The linear operator At ∈Rd×d for approximating Pt−1→t is obtained by solving the regularized least-square solution

> this paper proposes auxiliary data enrichment (ADE) to improve the prediction by leveraging unlabeled auxiliary data from arbitrary sources.

(SLDC, arXiv:2511.09926 v1.)

**Transport keys** (arXiv:2606.02860 v1, 1 Jun 2026) supply the one part HopDC lacks: the anchors are kept examples of the
earlier task, passed through both checkpoints. It uses them to map live activations back into a kept old decoder, not to
carry stored class statistics forward.

> Anchors are ordinary examples from the earlier task and are passed through both checkpoints.

(Transport keys, arXiv:2606.02860 v1.)

**What is left for RRM, stated plainly.**
- The **combination** of the stream's own kept rows as the anchor set (as in transport keys) with the transport of stored
  class statistics (as in HopDC and SLDC). The kept rows are in-distribution for the classes, labelled, and doubling as ER
  rows.
- The **linear ridge relation with its exactness property** (h′ = Lh for a linear change L on the anchors' span).

Both are small changes to published methods. HopDC's theory bounds the error by anchor density and the drift's Lipschitz
constant. It does not require the anchors to come from the stream.

## Judgement calls, for the investigator's review

- **P5: HopDC read close, not states.** This is the call that could move P5, and with it the worth rule.
  - **For states:** HopDC transports stored class Gaussians by the measured movement of a fixed, kept anchor set, weighted by
    each sample's relation to the anchors in the old space. That is P5 as worded.
  - **For close:** its relation is a kernel (softmax attention) smoother, not RRM's linear ridge relation. Its anchors are
    external unlabeled images (1,024, plus current-task samples in the main runs), not a few kept rows of the stream. The
    caller's instruction was "states needs the full mechanism; partial = close".
  - A reviewer who weighs the wording over the mechanism would grade P5 REDUNDANT. The investigator should decide this
    explicitly before `grade_w.py` runs.
  - Transport keys (arXiv:2606.02860 v1) close the anchor-provenance gap in a neighbouring use: anchors that are kept
    examples of the earlier task, passed through both checkpoints, with an alignment map fitted on them. That map carries
    live activations back into a kept old decoder, not stored statistics forward. Read together, HopDC, SLDC + ADE and
    transport keys publish every ingredient of RRM's transport. The only thing not found is the combination with a linear
    ridge relation fixed at each class's cut.
  - Either way, the RRM − STALE ablation no longer tests a new idea. It tests anchor provenance and the linear relation
    against a published anchor-drift transport. A fair comparator arm would be HopDC-style attention transport on the same
    kept anchors.
- **P3 has no states.** No source was found that keeps a few raw exemplars and stored full-class statistics and uses the
  exemplars to correct the statistics.
  - MEA-hybrid is the nearest: images plus stored features, with the features adapted by a map trained on current data.
  - "Heads collapse, features stay" (ICLR 2026) names the need, since statistics from small buffers are biased, and proposes
    correcting them without doing so.
- **P7 is split, and the split is by regime.**
  - Linear maps were best or sufficient for learners trained from scratch (LDC's ablation) and under a linear-constraint
    design (BFP).
  - For pre-trained ViTs, linear maps compensate "appropriately" but leave large residuals (SLDC). They lose to local or
    non-linear maps (HopDC, BiCyc) or to piecewise-linear mixtures (Dual-E).
  - BiCyc's authors note that capacity is not separated from form.
  - SLDC and GATF are each recorded twice, as states or close and as contradicts, because each asserts both halves.
  - "Contradicts" follows the caller's definition (a linear map fails, or a non-linear map is needed). Under RQM's
    existential negation alone, these would read "bears".
- **Scope.** P7's contradicting sources are mostly on pre-trained ViTs; RRM's learner is SEC1's MLP trained from scratch. The
  closest evidence for RRM's regime is LDC (states) and BiCyc on a ResNet-18 CIFAR-100 learner (contradicts).
